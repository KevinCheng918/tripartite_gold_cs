## 需求

## 待釐清

- 紀錄來源：手動填寫（開發者每次上版手動登打）還是自動從 git commit / PR 產生？
- 顯示形式：彈出視窗列表、跑馬燈、還是獨立頁面？
- 是否需要分類（新增/修改/刪除）與時間排序，是否所有客服帳號都看得到（見 [[rbac]]）？
